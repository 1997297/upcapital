INSTALL INTO YOUR EXISTING PHASE 2 PROJECT

1. Extract this ZIP.
2. Copy the included folders/files into your existing upcapital-platform folder.
3. Allow Windows to replace/merge files.

- app/page.tsx
- app/phase3-marketing.css
- components/marketing/home-page.tsx
- components/marketing/marketing-navbar.tsx
- public/brand/*

IMPORTANT CSS STEP
Open app/globals.css.

If it DOES NOT already contain:
